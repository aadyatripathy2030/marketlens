Video exporter

Renders an animation to a video file at full resolution. Recording happens in real time, so a 50-second clip takes 50 seconds. Leave the tab in the foreground while it runs — a backgrounded tab throttles the frame timer and the output stutters.

Ready.

1440 × 2160 is 2:3, not 9:16. TikTok, Reels and Shorts are all 9:16, so a 2:3 upload gets pillarboxed or centre-cropped. 1080 × 1920 is the native size and the safe default; 1440 × 2560 is the same shape at higher resolution. The 2:3 option is here because you asked for it — the animation letterboxes itself inside it rather than stretching.

Output is .mp4 where Chrome supports it, falling back to .webm. A webm from MediaRecorder has no duration in its header, so Finder and QuickTime report it as a second or two even when every frame is there — mp4 avoids that.

For DaVinci Resolve, run the file through tools/for-resolve.command first. MediaRecorder writes a fragmented mp4 and Resolve refuses those without explaining why. That script remuxes it with avconvert, which ships with macOS — nothing to install, no re-encode, about two seconds. Double-click it to convert the newest recording in Downloads. TikTok, Instagram and QuickTime all accept the file as it comes out of here; only Resolve needs the extra step.

If you would rather use ffmpeg:
ffmpeg -i in.webm -c:v libx264 -pix_fmt yuv420p -crf 18 out.mp4
